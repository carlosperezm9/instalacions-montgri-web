# Instal·lacions Montgrí — Web corporativa

Web informativa y de contacto para Instal·lacions Montgrí (fontanería, electricidad, climatización y gas en L'Estartit y el Baix Empordà).

## Estructura
Sitio estático de una sola página (`index.html`), sin dependencias externas ni build necesario — el logo va incrustado en el propio HTML.

## Despliegue
Este proyecto está pensado para desplegarse en [Vercel](https://vercel.com) como sitio estático:
1. Conecta este repositorio desde el panel de Vercel ("Add New" → "Project" → "Import Git Repository").
2. Framework Preset: **Other** (no requiere build).
3. Deploy.

Cualquier cambio que se haga `push` a la rama `main` se desplegará automáticamente.
